# EduConnect

EduConnect is a full-stack online learning platform that allows instructors
to publish courses and students to browse, enrol in, rate, and review them.

## Technology Stack

### Frontend

- React
- TypeScript
- Vite
- React Router
- Axios
- React Hook Form
- Zod
- Tailwind CSS

### Backend

- Node.js
- Express
- TypeScript
- MongoDB
- Mongoose
- JWT
- bcrypt

## Main Features

- User registration and authentication
- Student and instructor roles
- Account management
- Course CRUD
- Course search and filtering
- Student enrolment
- Course ratings and reviews
- Protected dashboards
